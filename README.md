# AI-Based Student Study Activity and Distraction Detection System

An AI-powered system that uses computer vision and machine learning to detect student study activities, identify distractions, and analyze focus levels in real time.

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Machine Learning
- Streamlit

## Features

- Study activity detection
- Distraction detection
- Real-time monitoring
- Focus level analysis
- Study session tracking
